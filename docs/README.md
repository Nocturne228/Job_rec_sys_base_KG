# 文档阅读路线

当前文档只服务于“项目怎样运行、技术为什么这样选、面试怎样诚实讲述”三个问题。

| 文档 | 唯一职责 |
|---|---|
| [`../README.md`](../README.md) | 项目入口、主故事、快速演示和证据摘要 |
| [`architecture.md`](architecture.md) | 技术要求、模块体系、数据流和功能计划 |
| [`data-and-evaluation.md`](data-and-evaluation.md) | 数据协议、指标定义、实测与推导/预期 |
| [`interview-guide.md`](interview-guide.md) | 简历表述、演示顺序和技术追问 |
| [`problem-solving.md`](problem-solving.md) | 五个最有价值的难题案例 |
| [`../AGENTS.md`](../AGENTS.md) | 开发、证据和范围约定 |
| [`../ref/README.md`](../ref/README.md) | 外部资料边界 |

阅读建议：首次了解按 README → architecture → interview-guide；审查实验时直接阅读
data-and-evaluation；准备难题回答时阅读 problem-solving。

证据冲突时按源代码/测试、版本化产物、数据评估文档、架构、README/面试指南、外部资料
的顺序判断。实测、推导/预期和目标必须明确区分。
